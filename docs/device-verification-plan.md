## 每台设备执行

1. 记录型号、系统、API、屏幕形态，取得调试授权。安装签名包，记录版本、SHA256、签名类型、安装和启动结果。
2. 冷启动记录 getSensorList 真实列表；空列表需有说明和刷新入口，不补造传感器。逐项核对真实回调字段、单位、时间戳与 UI；无回调不能把初始零值画成数据。
3. 用安全的物理变化检查运动、光照、接近等支持项；请求频率是建议，记录实际间隔，不能承诺精确达到。更改频率先取消旧订阅，不重复采集。事件型传感器静止无事件不能误报连续数据故障。
4. 暂停后 UI 不追加点、订阅关闭；恢复仅一个订阅；清空无遗留；点数与内存有界。快速操作验证无竞态。
5. Home、锁屏和切换应用后确认后台取消订阅；回前台按用户暂停状态恢复；用户暂停后不能自动开启。离开页面和进程后停止。
6. 有计步的设备上验证主动开启、授予、拒绝、撤销、重试；未授权不订阅计步且普通功能可用；累计值不标为当天。
7. 验证权限错误、服务异常、空列表、延迟、异常数值和重试；保留错误码证据，技术日志不记录原始读数。
8. 验证触控、键鼠、遥控输入和圆屏，控件可达、焦点可见、文案与曲线无关键裁切，尺寸变化正确重绘。长时前台和频率切换检查流畅、内存有界、耗电，结束停止采集，网络观察无 App 传输。

# 宿主机逻辑测试

在工程根目录执行：

    node tests/host/run.cjs

脚本使用已安装 DevEco Studio SDK 内的 TypeScript 与真实 apiAvailable 兼容性转换器 将工程的实际 .ets 模型、原生适配器和控制器转译后，在隔离的 VM 中注入传感器、权限、时钟和定时器替身。可用 DEVECO_STUDIO_HOME 指定 DevEco Studio 的 Contents 目录。

验证了本机枚举、API 版本保护、权限未授权与撤销、显式授权、授权回调竞争、前后台和暂停、逐项关闭、回调身份、硬件频率范围、非法样本、采样显示抽取、历史容量和时间范围、事件传感器、空列表、服务异常和停止失败重试。测试数据仅存在于测试脚本内，生产工程不包含模拟数据源。

这些测试验证采集逻辑，不替代 ArkTS 编译器检查、ArkUI 运行测试、真实设备传感器验收或签名安装验证。

签名脚本的隔离回归测试：

    python3 tests/host/signing-script.cases.py

该测试复制实际Debug签名脚本到临时工程，使用测试凭据和构建替身，验证成功、构建失败和SIGTERM时恢复配置原始字节及权限、释放锁，以及已有构建锁时不读取配置和短密码日志脱敏。测试不读取真实私钥，不生成实际发布包。
